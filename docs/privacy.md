# Overskin privacy policy

*Last updated: 22 November 2026*

Overskin is a screenshot and screen-recording app for Windows. It works entirely on your PC.
This policy covers both the Microsoft Store version and the version downloaded from GitHub.

## The short version

- Overskin doesn't collect, send or sell any information about you.
- There is no account, no sign-in, no analytics, no advertising and no telemetry.
- The Microsoft Store version makes no network requests at all.
- The GitHub version's only network request is asking GitHub whether a newer version exists,
  which you can turn off.

## What stays on your PC

Everything Overskin makes or reads stays on your PC, in places you control:

- **Captures** (screenshots, videos and GIFs) are saved to `Pictures\Overskin`, or to the
  folder you choose in Settings. Nothing is uploaded.
- **Settings** are saved in a file on your PC. The Microsoft Store version keeps them in its own
  private app storage, which Windows removes when you uninstall it.
- **The search index**: to let you search your captures by the words in them, Overskin reads the
  text in your screenshots with the text recognition built into Windows and keeps that text in
  an index file on your PC. The recognition runs offline.
- **Pinned pictures** that were pasted rather than opened from a file are kept in a cache on
  your PC, so they can come back when Overskin starts. They are deleted when you close the pin.
- **Crash reports**: if Overskin crashes, it saves a short report on your PC with the error
  and the Windows version. Your user name is removed from file paths in it. The report is never
  sent anywhere; you can choose to attach it to a bug report yourself (Settings → About →
  Crash reports).

## Microphone and camera

Overskin only uses your microphone or webcam while you are recording a video with that option
turned on. Windows asks for your permission first, and you can change it at any time in
Windows Settings → Privacy & security. The sound and picture go only into the video file saved
on your PC.

## Your screen and clipboard

Overskin reads your screen only when you capture or record it, and the clipboard only when you
copy or paste. When it hides private details (emails, card numbers, addresses and similar), it
finds them on your PC; nothing is sent to be checked.

## Network

- **Microsoft Store version**: makes no network connections. Updates are delivered by the
  Microsoft Store, under Microsoft's own privacy statement.
- **GitHub version**: when Overskin starts, and twice a day while it runs, it asks GitHub for
  the latest Overskin release. That request contains nothing about you beyond what any web
  request carries (such as your IP address, which GitHub receives). If you choose to install an
  update, the installer is downloaded from GitHub. Turn the check off in Settings → About. See
  GitHub's privacy statement for how GitHub handles requests.

If you open a link yourself (for example a web address found in a QR code), it opens in your
own web browser.

## Children

Overskin doesn't collect information from anyone, including children.
